\section{\large\textnormal{Концентрация примеси в базе $N_\text{б}$ задана по варианту. При каком напряжении уровень инжекции $\delta = 1$?}}

\begin{figure}[H]
    \centering
    \begin{minipage}[t]{0.3\textwidth}
    \vspace{0em}
    \begin{tabularx}{\textwidth}{|X|}
        \hline
        \multicolumn{1}{|C|}{Дано} \\
        \hline
        $N_\text{б} = 10^{18}$ см$^{-3}$ \\
        $\delta = 1$ \\
        $n_i = 1.45 \cdot 10^{10}$ см$^{-3}$ \\
        $T = 300$ К \\
        \hline
        \multicolumn{1}{|C|}{Найти} \\
        \hline
        $U(\delta = 1)$ — ? \\
        \hline
    \end{tabularx}

    \vspace{0.8em}
    Уровень инжекции $\delta$ в базе $p$-типа определяется как
    \begin{equation*}
        \delta = \frac{\Delta n(0)}{p_{p0}} = \frac{\Delta n(0)}{N_\text{б}}
    \end{equation*}
    где избыточная концентрация неосновных носителей на границе ОПЗ:
    \begin{equation*}
        \Delta n(0) = n_{p0}\left(e^{\frac{U}{\varphi_T}} - 1\right)
    \end{equation*}
    а равновесная концентрация:
    \begin{equation*}
        n_{p0} = \frac{n_i^2}{N_\text{б}}
    \end{equation*}
    \end{minipage}\hfill\begin{minipage}[t]{0.7\textwidth}
        \vspace{0em}
        \begin{tabularx}{\textwidth}{C|}
            \hline
            Решение \\
            \hline
        \end{tabularx}

        \vspace{0.5em}
        \hspace{0.025\textwidth}
        \begin{minipage}[t]{0.95\textwidth}
            Равновесная концентрация неосновных носителей (электронов) в базе:
            \begin{equation*}
                n_{p0} = \frac{n_i^2}{N_\text{б}} = \directlua{
                    tex.sprint("\\frac{("
                               .. include.value_with_mantice(data.n_i, 3, 0, 0) .. 
                               ")^2}{"
                               .. include.value_with_mantice(data.N_b, 3, 0, 0) .. 
                               "} = "
                               .. include.value_with_mantice(data.n_p0, 3, 0, 0))
                } \text{ см}^{-3}
            \end{equation*}

            По определению уровня инжекции при $\delta = 1$:
            \begin{equation*}
                \delta = \frac{\Delta n(0)}{N_\text{б}} = \frac{n_{p0}}{N_\text{б}}\left(e^{\frac{U}{\varphi_T}} - 1\right) = 1
            \end{equation*}
            Отсюда:
            \begin{equation*}
                e^{\frac{U}{\varphi_T}} = 1 + \frac{N_\text{б}}{n_{p0}} = 1 + \frac{N_\text{б}^2}{n_i^2}
            \end{equation*}
            Так как $\frac{N_\text{б}^2}{n_i^2} \approx 4.76 \cdot 10^{15} \gg 1$, напряжение прямого смещения на переходе:
            \begin{equation*}
                \begin{aligned}
                    U &= \varphi_T \ln\left(1 + \frac{N_\text{б}^2}{n_i^2}\right) \approx 2\varphi_T \ln\left(\frac{N_\text{б}}{n_i}\right) = 2\varphi_{0\text{б}} = \\
                    &= \directlua{
                        tex.sprint(include.value_with_mantice(data.phi_T, 3, 0, 0) .. 
                                   " \\ln\\left(1 + \\frac{(" .. 
                                   include.value_with_mantice(data.N_b, 3, 0, 0) .. 
                                   ")^2}{(" .. 
                                   include.value_with_mantice(data.n_i, 3, 0, 0) .. 
                                   ")^2}\\right) \\approx " .. 
                                   include.value_with_mantice(data.U_delta_1, 3, -1, 0))
                    } \text{ В}
                \end{aligned}
            \end{equation*}

            \textbf{Физический смысл полученного результата:}
            \begin{itemize}
                \item Величина $U$ равна удвоенному встроенному потенциалу базы: $U = 2\varphi_{0\text{б}} = 2 \cdot 0.467\text{ В} \approx 0.933\text{ В}$.
                \item При этом напряжении избыточная концентрация инжектированных электронов достигает равновесной концентрации дырок ($\Delta n(0) = N_\text{б} = 10^{18}\text{ см}^{-3}$), что является границей применимости теории слабого уровня инжекции ($\delta \le 1$).
                \item Напряжение $U = 0.933\text{ В} < \varphi_k = 1.052\text{ В}$, что подтверждает корректность барьерного режима перехода.
            \end{itemize}

            \vspace{0.4em}
            Ответ: $U \approx \directlua{
                tex.sprint(include.value_with_mantice(data.U_delta_1, 3, -1, 0))
            } \text{ В} = 2\varphi_{0\text{б}}$.
    \end{minipage}\end{minipage}

    Стационарное уравнение диффузии в квазинейтральной $n$-базе ($E \approx 0$):
    \begin{equation*}
        \frac{d^2 \Delta p_n(x)}{dx^2} - \frac{\Delta p_n(x)}{L_p^2} = 0
    \end{equation*}
    Решение для полубесконечной базы ($\Delta p_n(x \to \infty) = 0$):
    \begin{equation*}
        \Delta p_n(x) = \Delta p_n(0) e^{-\frac{x}{L_p}}
    \end{equation*}
    Полная концентрация:
    \begin{equation*}
        p_n(x) = p_{n0} + \Delta p_n(x)
    \end{equation*}
    Условия Шокли при $x = 0$:
    \begin{equation*}
        p_n(0) = p_{n0} e^{\frac{U}{\varphi_T}}
    \end{equation*}
    \begin{equation*}
        \Delta p_n(0) = p_{n0}\left(e^{\frac{U}{\varphi_T}} - 1\right)
    \end{equation*}
